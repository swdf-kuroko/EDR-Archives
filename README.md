◆　SNSへの画像付き宣伝について
----------------------------------------------------------------------------------------------

現在多くのwebサービスがAIを導入し各自分析を行っている時代です。
本件に関して私自身の考えは、
実際に自作シナリオを画像検索にかけてどこまで読めるか確認した結果に基づき、
「ゲーム画面のスクリーンショットという性質上、複数の要素で構成された画像を投稿するため
学習させたい項目を的確かつ細かく指定しない限り構成された画像から1つを抜き出すことは困難。」
としていました、現在は特定できるほど精度が上がっていますが、
・「プロンクトを入力する当人の文章力」が精度に直結する
・「目的が誹謗中傷か単にアイディア相談」かを見抜くの使用者自身なので限りなく不能
・各種Webサービスを使用している時点でビックデータ事業(現AI事業？)に参加している

の考えは変わっていません。そのため
各シナリオに付属する「使用素材著作権一覧およびインポート画像著作権一覧」に
記載されている各作者の方針を遵守した上で"すべてのSNS、ブログサービス"への掲載を許可します。
(施行日：2024/11/11　更新：2026/10/22)

◆　クロスオーバーとエクスポートとインポート使用・利用に関して
----------------------------------------------------------------------------------------------

まず、シナリオ中で公開している範囲がクロスオーバーの対象になりますが、
クロスを希望するシナリオに対する悪意のある内容及び、
ユーザーが著しく不快になる・不利益を被る(例：1名を残して強制キャラロスト)を含む場合
公開の停止を求める場合があります。
もちろん、クロスの希望は受け付けてます。必ずDL確認しに行きます。

スキルやアイテムカードをエクスポートしたデータを使いたい場合は上記に加えて、
貴社の製作中シナリオや連れこみキャラに搭載す際は、
・カード絵の変更
　著作者がすべて私の物でお使いになりたいデータがスキルやアイテムの場合のみ。
　複数の著作者にまたがる物は元となっている画像配布先の規約に従い、
　必要に応じて画像ごとエクスポートしてください。
　このとき、使用している画像が消失していることが判明した場合は差し替えても構いません。
・キャラクターの取り扱いについて
　ゲスト出演(使用)のみ可能とし持ち物も含めて一切の変更は認めません。

・内容の調整と派生カードの作成
　Py専用機能が組み込まれているスキルの1.50系で再現が不可能なモノはエクスポート対象外とします。
　エクスポート利用可能なものは、全エンジンで問題なく作動するカードのみ原形をとどめる範囲に限ります。
　それらのスキルは効果別に分割するといった修正は可能です。
　また、内容の変更の有無にかかわらず再販は一切禁止です。
　別途シナリオ毎にエクスポート利用可能なデータを指定する場合があります。

(施行日：2023/11/07・更新：2025/03/26
　「インポート」から「エクスポートしたデータ」に表記変更、内容の修正の対象範囲を変更)

・独自キーコードに関して
　特産品は命名規則に準じて「産地タグ」を付与しています。
　普及的な加工用アイテムには「初出シナリオ名」といった独自KCは付与せず一般的なKCを採用してますので
　現在公開中の様々なシナリオで対応するKCイベントが発生するはずです。
　独自キーコードや希少キーコードが含まれる場合はシナリオ付属の説明書に入手先などを明記します。
